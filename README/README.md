# E-Commerce Sales Analytics using Python

## Project Overview
This project analyzes e-commerce sales data using Python and visualizes business insights using different charts.

## Tools Used
- Python
- Pandas
- Matplotlib
- VS Code

## Dataset
- ecommerce.csv

## Features
- Data Cleaning
- Sales Analysis
- Profit Analysis
- Category-wise Sales
- State-wise Sales
- Bar Chart
- Pie Chart
- Line Chart
- Scatter Plot
- Histogram
- Dashboard

The project generates:
- Total Sales
- Total Profit
- Highest Sales Product
- Highest Profit Product
- Business insights using charts
